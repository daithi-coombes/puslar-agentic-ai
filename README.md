# Agentic AI for Pulsar IDE

> This project is currently in development. Please feel free to help out in the
> [issues](https://github.com/daithi-coombes/puslar-agentic-ai/issues)

This plugin aims to provide Agentic AI abilites locally. It uses `ollama` and
`chromadb` under the hood.

Please see the dev branch for current, unversioned, Proof of Concept
